Сюда при установке обновления попадают программы удалённого доступа:
  ITRemoteViewer.exe     — программа специалиста
  ITRemoteAgent-x64.exe  — агент для 64-битных Windows 7–11
  ITRemoteAgent-x86.exe  — агент для Windows XP и 32-битных Windows
Они входят в полный архив обновления (scripts/make-update.sh берёт их из сборки репозитория RemoteSupport).
